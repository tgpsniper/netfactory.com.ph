🔍 System Overview

The Netfactory CRM runs on Ubuntu 24.04 and consists of:

  • CRM Frontend: Web-based interface at /var/www/netfactory.com.ph/html/crm/
  • API Backend: Node.js application at /home/ubuntu/Node.js_API/j2-api/
  • Database: PostgreSQL database named ispdb
  • Web Server: Nginx serving on port 80/443
  • Process Manager: PM2 managing Node.js processes

📦 Backup Types Explained

💾 System Backup (Partial)

Size: ~56 MB | Time: 10-15 seconds

What's included:

  • CRM files (HTML, CSS, JavaScript)
  • API source code (without node_modules)
  • Database schema (table structures only)
  • Admin users data
  • PM2 configuration
  • Monitor state

Use case: Daily backups, quick recovery of files, version control

⚠️ Note: This does NOT include environment variables, SSL certificates, or complete database. You'll need the existing server infrastructure to restore.

🚨 Disaster Recovery Backup (Complete)

Size: ~1.5 MB compressed (8 MB uncompressed) | Time: 30-60 seconds

What's included:

  • Everything in System Backup PLUS:
  • Complete database (all tables and data)
  • Environment variables (.env with API keys)
  • Nginx configuration
  • SSL certificates (Let's Encrypt)
  • SSH keys for RADIUS server access
  • Automated RESTORE.sh script

Use case: Server migration, complete disaster recovery, rebuilding from scratch

✅ Recommended: Create a Disaster Recovery backup at least once per week and before major changes.

💾 Creating Backups

1 Access Backup Page

In your CRM, click 💾 System Backup from the left sidebar menu.

2 Choose Backup Type

Click either:

  • Create System Backup — for quick daily backups
  • Create DR Backup — for complete disaster recovery

3 Wait for Completion

System Backup: ~15 seconds | DR Backup: ~60 seconds

You'll see a success message with the backup size.

4 Download the Backup

The backup appears in the "All Backups" table. Click Download to save it to your computer.

💡 Tip: Store backups in multiple locations: local computer, external drive, cloud storage (Google Drive, Dropbox).

📋 Restoration Requirements

For System Backup Restoration

You need an existing Netfactory server with:

Component Requirement
Operating System Ubuntu 24.04 (already installed)
Node.js Version 20.x (already installed)
PostgreSQL Version 16+ (already installed)
Nginx Latest version (already installed)
PM2 Latest version (already installed)
Access SSH access with sudo privileges

For Disaster Recovery Restoration

You need:

Component Requirement
Server Fresh Ubuntu 24.04 server (can be completely blank)
RAM Minimum 2 GB (4 GB recommended)
Disk Space Minimum 20 GB free
Network Internet connection
Access SSH/root access (password or key)
Domain (optional) DNS pointing to new server IP if changing servers
⚠️ Important: The RESTORE.sh script will install everything automatically. You don't need to install Node.js, PostgreSQL, or any other software beforehand!

🔄 Restoring System Backup

Prerequisites: Existing Netfactory server with all software installed

1 Upload Backup to Server

From your computer, upload the backup file to the server:

scp 20260217_154818.tar.gz ubuntu@your-server-ip:~/

Windows users: Use WinSCP or FileZilla to upload the file to /home/ubuntu/

2 SSH into Server

ssh ubuntu@your-server-ip

3 Extract the Backup

cd ~
tar -xzf 20260217_154818.tar.gz
cd 20260217_154818

4 Restore CRM Files

sudo cp -r crm_backup/* /var/www/netfactory.com.ph/html/crm/
sudo chown -R www-data:www-data /var/www/netfactory.com.ph/html/crm/

5 Restore API Files

cp -r j2-api_backup/* /home/ubuntu/Node.js_API/j2-api/
cd /home/ubuntu/Node.js_API/j2-api
npm install
npx prisma generate

6 Restore Database (Optional)

Only if you need to restore admin users:

cd ~/20260217_154818
sudo -u postgres psql ispdb < admin_users_data.sql

7 Restart Services

pm2 restart all
sudo systemctl restart nginx

8 Verify Restoration

Open your browser and go to: https://netfactory.com.ph/crm/

Check that everything works correctly.

🚨 Restoring Disaster Recovery Backup

Use case: Building on a brand new server or recovering from complete system failure

⚠️ CRITICAL: This will COMPLETELY rebuild your server. Only use on a fresh Ubuntu 24.04 installation or when recovering from disaster!

1 Provision Fresh Server

Create a new Ubuntu 24.04 server with:

  • At least 2 GB RAM (4 GB recommended)
  • 20 GB+ disk space
  • SSH access enabled

Cloud providers: AWS EC2, DigitalOcean, Linode, Vultr all work great

2 Update DNS (If Changing Servers)

Point your domain netfactory.com.ph to the new server's IP address.

Wait 5-15 minutes for DNS propagation.

3 Upload Backup to New Server

From your computer:

scp 20260217_155805.tar.gz ubuntu@NEW-SERVER-IP:~/

Windows: Use WinSCP/FileZilla to upload to /home/ubuntu/

4 SSH into New Server

ssh ubuntu@NEW-SERVER-IP

5 Extract Backup

cd ~
tar -xzf 20260217_155805.tar.gz
cd 20260217_155805

6 Make Restore Script Executable

chmod +x RESTORE.sh

7 Run the Automated Restore

sudo ./RESTORE.sh

When prompted, type yes and press Enter.

This will take 15-20 minutes and will automatically:

  • Install Node.js, PostgreSQL, Nginx, PM2
  • Restore all files
  • Import complete database
  • Configure SSL certificates
  • Start all services

8 Verify Everything Works

After the script completes, run:

pm2 status
curl http://localhost:3001/api/health

Then open your browser: https://netfactory.com.ph/crm/

9 Configure PM2 Startup (First Time Only)

If this is a brand new server, configure PM2 to start on boot:

pm2 startup
# Copy and run the command it shows you
pm2 save
✅ Success! Your entire system has been restored. All services, databases, configurations, and files are now running on the new server!

🔧 Troubleshooting

Problem: "Permission denied" during restore

Solution: Make sure you're using sudo for commands that need it:

sudo ./RESTORE.sh
sudo cp -r crm_backup/* /var/www/netfactory.com.ph/html/crm/

Problem: "npm install" fails

Solution: Make sure Node.js is installed:

node --version
npm --version

If not installed, run:

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Problem: Database restore fails

Solution: Check PostgreSQL is running:

sudo systemctl status postgresql
sudo systemctl start postgresql

Problem: Nginx shows "502 Bad Gateway"

Solution: Check if API is running:

pm2 status
pm2 logs j2-api

Restart if needed:

pm2 restart j2-api

Problem: SSL certificates don't work after restore

Solution: If you changed domains, regenerate certificates:

sudo certbot --nginx -d netfactory.com.ph

Problem: Can't SSH into new server

Solution: Check:

  • Firewall allows port 22: sudo ufw allow 22
  • Security group allows SSH (cloud providers)
  • Using correct IP address
  • SSH key is correct

Still Having Issues?

📞 Get Help:

  • Check API logs: pm2 logs j2-api
  • Check Nginx logs: sudo tail -f /var/log/nginx/error.log
  • Check system logs: sudo journalctl -xe
  • Contact your system administrator
🎉 You're all set! You now know how to backup and restore your Netfactory CRM system. Remember to create regular backups and test your restore process periodically!
